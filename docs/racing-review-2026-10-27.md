## 구현 시 결정한 내용

- 시작 GPS는 기존 FAST 품질 조건에 더해 현재 시각 기준 3초 이내,
  정확도 0 초과 50m 이하인지 다시 검사한다. 코스 좌표로 대체하지 않는다.
- 저장 기록 재도전은 원래 시작 위치 근처라는 검사를 유지하고, GPS 대기 후에도
  다시 검사한다. 과거의 별도 출발선 통과/armed 단계는 공동 카운트다운 출발로 바꿨다.
- 새 왕복이 원래 출발지로 복귀하는 코스라면 실제 공동 출발 GPS로 돌아온다.
  카운트다운 중 이미 이동한 구간을 뺀 실제 코스 길이와 체크포인트를 사용한다.
  다른 복귀 목적지를 명시한 코스와 저장 코스의 도착점은 유지한다.
- GPS watcher는 하나다. 기존 일반 Ride를 지우거나 잘라내지 않는다. 레이싱용
  Ride 캡처가 같은 콜백과 기존 `ride-foundation.js`의 보정 로직을 재사용한다.
  GPS/이동 시간 보정 라이브러리 자체는 이번 작업에서 수정하지 않았다.
- 출발 앵커는 실제 시작 시각의 위치 스냅샷(`source: race-start`)이다.
  이전 원본 GPS 표본의 측정 시각을 바꾸지 않는다. 이후 측정 시각이 출발보다
  이른 표본은 레이싱 캡처에 넣지 않는다. 일시정지/재개는 두 캡처에 적용하며,
  레이싱 종료 뒤에도 기존 일반 Ride는 계속 기록할 수 있다.
- 반환점 통과 시 GPS 앵커(`race-turnaround`)를 보존한다. 거리 배치 보정이 그
  순간의 경로 표본을 생략했더라도 저장 경로에 앵커를 넣고 최종 인덱스를 저장한다.
  구기록은 알려진 반환점의 경로 투영을 사용하고, 복원 정보가 없거나 끝점으로
  해석되면 임의 반환점을 만들지 않고 재도전을 거절한다.
- Ghost 보간은 확정된 두 진행 거리 사이에서만 경로 이력을 따라 그린다.
  공식 격차/이동 시간/완주 판정을 수정하거나 미래 진행 거리를 추가하지 않는다.
  표시 지연은 GPS 갱신 간격에 따라 최대 3초다. 정지·수동 일시정지·오래된 GPS·
  재탐색·종료 시 프레임을 중단하거나 새 경로로 초기화한다.
- 파란 선은 두 라이더 및 보간 중인 Ghost에게 필요한 이전/현재 경로 구간을
  사용한다. 좌표 중심 앵커는 두 화살표 모두 `.5, .5`다. 지도 회전은 추가하지 않았다.
