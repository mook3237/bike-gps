# RideMate 메인지도 · 현재 디자인 화면 코드

현재 확정된 메인지도 디자인을 기준으로 만든 화면 코드입니다.

## 파일
- index.html : 화면 구조
- styles.css : 모바일 UI 스타일
- app.js : 버튼/탭의 기본 동작
- assets/map-reference.jpg : 현재 디자인의 지도 시각 참고용 이미지

## 실행
index.html을 브라우저에서 열면 됩니다.

## 실제 앱 연결 시
`assets/map-reference.jpg`는 실제 지도 대신 사용하는 시각 참고용입니다.
나중에 Kakao Maps 등 실제 지도 SDK를 연결할 때 `.map` 영역의 이미지를 지도 컨테이너로 교체하면 됩니다.

현재 구현된 동작:
- 목적지 검색 버튼
- 메뉴 버튼
- 집 / 회사 / 즐겨찾기
- 나침반
- 지도 레이어
- 확대 / 축소
- 지도 / 레이싱 / 기록계 탭 전환

화면 디자인 자체는 유지하고, 이후 API/GPS/실제 지도 로직을 연결하는 방식으로 확장합니다.


[v6 화면 기준 정리]
- 줌 +/- 위치: top 퍼센트 방식 제거, bottom:105px로 하단 탭 기준 고정
- 현재위치 버튼: 이전 PNG/중복 CSS 완전 제거, 순수 CSS 타깃 아이콘 하나로 정리
- 하단 지도/레이싱/기록계: 숨겨놓은 아이콘 HTML 자체 제거, 글자만 유지
- 검색창/집/회사/즐겨찾기/지도/우측 방향·레이어/하단 구조는 변경하지 않음

[v7 수정]
- 지도 레이어 버튼 제거
- 화면 중앙 파란 현재위치 표시가 두 개 보이던 원인 제거: 추가 overlay 점 삭제
- 현재위치 복귀 버튼의 타깃 심볼 크기 확대
- 나머지 UI/배치는 변경하지 않음
